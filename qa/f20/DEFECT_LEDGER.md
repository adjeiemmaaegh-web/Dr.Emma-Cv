## Rules
Severity S0 = immediate data/security emergency; S1 = release-blocking; S2 = important quality or truthful UX problem; S3 = minor. **Status must not be upgraded from NOT RUN/RISK to PASS without a linked environment, exact commit, test artifact and reviewer.** For findings in an F-owned harness, the feature owner fixes production code in its path; F adds failing tests and independently reruns. No synthetic test case is permitted to contain an actual applicant's CV, contact data, AI API key or job-account credential.
