# LinkedIn-to-CV and profile coach development increment (2026-11-17)

**Status:** unmerged development candidate; no public release or parity claim.

## User-authorized inputs
The coach never visits a LinkedIn URL, scrapes a profile, logs in, or invokes a LinkedIn API. A member may explicitly provide their own pasted profile text, selected official CSV files, or a local ZIP export. Only Profile.csv, Positions.csv, Skills.csv, Education.csv, Certifications.csv and Projects.csv are recognized; messages, connections and unrelated data are intentionally ignored. No automatic upload, background sync or network fetch is added.

The official route is: LinkedIn -> Settings & Privacy -> Data Privacy -> Download your data -> Request archive, as available to the member. Export categories and availability differ by account and region; the user must initiate the export. This app does not authorize or impersonate LinkedIn access.

## What changed
- Comparison covers repeated employers with distinct roles, matching dates, location, missing experience details, About-vs-summary differences, education/degree mismatches, skills present on only one side, and missing certifications. Missing export categories are **unknown**, never treated as empty LinkedIn records.
- Source-cited draft proposals extend the existing headline and empty-About suggestions with a short-About alternative and CV-backed skills recommendations. No new metric, credential or achievement is invented; every suggestion requires review and manual action.
- Prioritized action plan separates discrepancies from informational opportunities, with explicit source paths where present. The comparison does not change LinkedIn or the CV.
- LinkedIn-to-CV conversion now returns a pending ImportReview and a **separate** proposed CV. It preserves original roles, education, summary, skills, certifications and projects and carries original export file-entry references. Explicit per-item acceptance and final confirmation are required to create a profile.
- CSV parsing has a bounded input size, and ZIP parsing inherits CRC, duplicate, directory and total-size checks.

## Honest limits
- This increment supplies source modules and synthetic tests. The currently mounted career-workspace view still only supports paste-text coaching; wiring ZIP upload, source side-by-side review and the conversion approval screen into the UI requires integration review by the experience/workspace owner.
- No LinkedIn OAuth, scraping, cookies, credentials, automated API access or profile URL ingestion.
- A user's LinkedIn download is not a third-party verification of each claim. All user-supplied data remains marked unverified until reviewed by the user.
- Recommendations and the action plan are explainable heuristics, not evidence of search ranking, applicant tracking system outcomes or recruiter response.
- Enhancv's publicly described LinkedIn coaching and resume import are benchmarking references; no measured superiority or feature parity has been established.
